🎮 Meshtastic Joystick Flash Tool

Flash Meshtastic firmware with 5-way joystick navigation support to Heltec V3 or V4

⚠️ Unsupported browser. Web Serial API requires Chrome 89+ or Edge 89+ on desktop. Download Chrome

① Select Your Board

Heltec WiFi LoRa 32 V3

ESP32-S3FN8 · SX1262 · 0.96″ OLED · 8 MB Flash · ~180 µA sleep

Heltec WiFi LoRa 32 V4

ESP32-S3R2 · SX1262 · 0.96″ OLED · Improved antenna · ~140 µA sleep

📌 Not sure which board you have? Check the silkscreen on the PCB — it will say WiFi LoRa 32(V3) or WiFi LoRa 32(V4).

② Connect Device

Not connected

🔌 Joystick Wiring Reference

Use any passive 5-way navigation joystick (RKJXK, SKRHAAE, or similar). All pins are active-LOW with internal pull-ups enabled.

Joystick PinGPIO (V3 & V4)Heltec Header Label
UP GPIO 1 IO1
DOWN GPIO 2 IO2
LEFT GPIO 4 IO4
RIGHT GPIO 5 IO5
CENTERGPIO 6 IO6
GND (COM)GNDGND
VCC 3.3 V3V3
💡 No resistors needed. Internal pull-ups are enabled in firmware. If your joystick module has its own pull-ups, omit the VCC wire.
