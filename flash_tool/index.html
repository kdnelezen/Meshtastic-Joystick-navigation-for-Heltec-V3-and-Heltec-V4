1 · Prerequisites

A

Browser

Use Google Chrome 89+ or Microsoft Edge 89+ on a desktop/laptop. Firefox and Safari do not support the Web Serial API required for flashing.

B

USB Cable

A USB-A to USB-C data cable (not charge-only). Charge-only cables lack the data wires. USB-C to USB-C cables may cause driver issues with the on-board CP2102 bridge.

C

CP2102 USB–UART Driver

The Heltec board uses a SiLabs CP2102 USB-to-serial chip. Install the driver if your OS does not recognise the port automatically. See Step 3 — Install USB Driver.

D

Firmware Binary

You need a compiled .bin file. Either download a pre-built release or build it yourself using PlatformIO (see Step 5).

ItemDetails / Where to Buy

3 · Install USB Driver

1

Windows & macOS

Download and install the SiLabs CP210x VCP driver:

SiLabs CP2102 Drivers →

After installing, unplug and replug the USB cable. The device should appear as COM3 (Windows) or /dev/cu.SLAB_USBtoUART (macOS).

2

Linux

The CP210x driver is included in the Linux kernel. Add your user to the dialout group so Chrome can access serial ports:

sudo usermod -a -G dialout $USER
# Log out and log back in for the change to take effect

The device will appear as /dev/ttyUSB0 or /dev/ttyACM0.

3

Verify the port appears

With the board connected, open Chrome → address bar → type chrome://device-log and look for a USB serial device entry. You can also check the OS device manager.

4 · Wire the Joystick

A passive 5-way joystick has one common pin and five switch pins (UP, DOWN, LEFT, RIGHT, CENTER). No external resistors are needed — the firmware enables internal pull-ups.

1

Connect GND first

Wire the joystick COM / GND pin to any GND pin on the Heltec header. This is the most important wire — all direction switches are active-LOW relative to this.

2

Connect direction pins

Wire each joystick direction to the corresponding GPIO on the right header of the Heltec board:

Joystick PinGPIOHeltec Header Label
UP GPIO 1 IO1
DOWN GPIO 2 IO2
LEFT GPIO 4 IO4
RIGHT GPIO 5 IO5
CENTER / CLICKGPIO 6IO6
3

VCC (optional)

If your joystick module has an indicator LED or active logic that needs power, connect its VCC pin to the Heltec 3V3 header pin. Pure passive switches do not need VCC.

💡 GPIO locations on the right header (top → bottom): GND, RST, IO0, IO36, IO35, IO34, IO21, IO20, IO19, IO18, IO17, IO16, IO15, IO7, IO6, IO5, IO4, IO3, IO2, IO1.
IO1, IO2, IO4, IO5, IO6 are near the bottom of the right header.
⚠️ Do NOT use: GPIO 0 (boot button), GPIO 8–14 (LoRa SPI), GPIO 17–18 (OLED I2C), GPIO 21 (OLED RST), GPIO 35 (LED), GPIO 36 (Vext). Using reserved pins will cause conflicts with on-board peripherals.

6 · Flash with This Web Tool

1

Serve the flash tool (required for Web Serial)

Web Serial only works over http://localhost or https://. Open a terminal in the repository root and run:

python3 -m http.server 8080

Then open http://localhost:8080/flash_tool/ in Chrome or Edge.

Alternatively, deploy this folder to any static HTTPS host (GitHub Pages, Netlify, etc.) and open the hosted URL.

2

Select your board

Click Heltec V3 or Heltec V4 in the Flash Tool tab.

3

Connect

Click Connect via USB. A browser dialog pops up listing available serial ports. Select the port labelled CP210x USB to UART Bridge (Windows: COMx, Linux/macOS: /dev/ttyUSBx or /dev/cu.SLAB_…).

4

Flash

Check Full chip erase before flash (strongly recommended for first install or if upgrading from a different firmware). Click ⚡ Flash Firmware. The tool downloads the firmware binary, auto-resets the board into bootloader mode, erases (if selected), and writes the firmware. Watch the progress bar and log. The whole process takes about 30–90 seconds.

5

Reset the board

After flashing completes the board resets automatically. The OLED should display the Meshtastic boot screen within a few seconds. If nothing appears, press the RST button on the board.

7 · Flash with PlatformIO (alternative to web tool)

If you prefer the command line over the browser-based tool, PlatformIO can build and flash in a single command. This works on Windows, macOS, and Linux.

Quick one-liner (build + flash)

# Heltec V3
pio run -e heltec_v3_joystick --target upload

# Heltec V4
pio run -e heltec_v4_joystick --target upload

First install: erase then flash

On a fresh board or when switching from different firmware, erase first:

# Step 1: erase the entire flash
pio run -e heltec_v3_joystick --target erase

# Step 2: upload the firmware
pio run -e heltec_v3_joystick --target upload

Specify serial port manually

PlatformIO auto-detects the port in most cases. If it picks the wrong port, specify it explicitly:

# Windows — find port with: pio device list
pio run -e heltec_v3_joystick --target upload --upload-port COM3

# macOS — find port with: ls /dev/cu.*
pio run -e heltec_v3_joystick --target upload --upload-port /dev/cu.SLAB_USBtoUART

# Linux — find port with: ls /dev/ttyUSB* or ls /dev/ttyACM*
pio run -e heltec_v3_joystick --target upload --upload-port /dev/ttyUSB0

🔌 Joystick Wiring Reference

A passive 5-way navigation joystick connects directly to the Heltec GPIO header. No external resistors are needed — all inputs use internal pull-ups (active-LOW logic).

Pin Mapping (Heltec V3 and V4 — identical)

Joystick FunctionGPIOHeltec Header LabelNotes
UP GPIO 1IO1Active-LOW, internal pull-up
DOWN GPIO 2IO2Active-LOW, internal pull-up
LEFT GPIO 4IO4Active-LOW, internal pull-up
RIGHT GPIO 5IO5Active-LOW, internal pull-up
CENTER / CLICKGPIO 6IO6Short press = SELECT, long press = BACK
GND (common)GNDGNDJoystick common / return pin
VCC (optional)3.3 V3V3Only if module needs power rail

❓ Frequently Asked Questions

Can I change which GPIO pins the joystick uses?

Yes. Edit the JOYSTICK_PIN_* values in platformio.ini under the relevant [env:...] section and rebuild. Avoid reserved pins (see the Wiring Reference tab).

Can I use an analog (thumbstick) joystick?

This firmware targets passive digital 5-way switches. An analog thumbstick (two potentiometers) requires an ADC-based driver variant and is not currently supported.

Will this work with Meshtastic Android / iOS apps?

Yes. The firmware runs standard Meshtastic BLE and Wi-Fi pairing. The joystick only affects the on-device OLED navigation; all app features work normally.

What LoRa region should I configure?

Set the region to match your country's ISM band allocation: US (915 MHz), EU_868 (868 MHz), EU_433 (433 MHz), etc. See meshtastic.org/docs →

Is AES encryption supported?

Yes. Meshtastic uses AES-256-CTR for all channel messages. The default public channel has a known key; set a custom PSK for a private group.

How do I update the firmware later?

Re-flash using this web tool or PlatformIO. For OTA (over-the-air) updates, use the Meshtastic app over Bluetooth — no USB cable needed after initial setup.

Does this support GPS?

Yes. Connect an external NMEA GPS module to the UART pins. The node will broadcast its position to the mesh. See Meshtastic docs for pinout and UART config.

Can I integrate this with the official Meshtastic firmware tree?

Yes. Copy src/input/JoystickInput.h and JoystickInput.cpp into the official firmware's src/input/ folder, instantiate JoystickInput in main.cpp, and call joystick.begin() in setup() and joystick.update() in loop(). See the full README for the exact integration code.

What is the maximum mesh range?

With clear line of sight, Meshtastic typically achieves 5–15 km per hop using the default LongFast modem preset (SF11 / BW250 / CR 4:5). Enable the LongSlow or VLongSlow preset for extended range at lower data rate.

How many nodes can be in a mesh?

Practically 30–100 nodes in a mesh before network congestion becomes significant. Store-and-forward modules can extend message delivery across sparse networks.

The web tool says "Unsupported browser". What do I do?

Install Google Chrome or Microsoft Edge (both version 89 or later). The Web Serial API used for flashing is not available in Firefox, Safari, or mobile browsers.
